## 一、基础概念体系

### 1.1 K线包含处理（第1-3课）

**定义**：当两根K线的高点和低点存在包含关系时（一根K线的高低点完全在另一根K线范围内），需要合并为一根K线。

**合并规则**：
- 上升趋势中：取两根K线的高点较高值和低点较高值（**高高**）
- 下降趋势中：取两根K线的高点较低值和低点较低值（**低低**）
- 趋势方向由前一根非包含K线确定

**重要**：包含处理是分型识别的前提，不处理包含关系就无法正确识别分型。

### 1.2 分型（第3-4课）

**顶分型**：三根处理后K线中，中间K线的高点最高，低点也最高。
**底分型**：三根处理后K线中，中间K线的低点最低，高点也最低。

**分型的重要性质**：
- 顶分型的高点称为"顶"，底分型的低点称为"底"
- 顶和底是缠论结构的原子单位
- 分型之间至少有一根独立K线

### 1.3 笔（第5-7课）

**定义**：连接相邻顶底分型的线段。

**笔的构成规则**：
- 从顶分型到底分型 = 向下笔
- 从底分型到顶分型 = 向上笔
- 顶底分型之间至少有一根非共用K线（处理后间隔 ≥ 4根）
- 连续同类型分型取极值：连续顶分型取最高，连续底分型取最低

**笔的方向性质**：
- 向上笔：起始于底分型，终止于顶分型
- 向下笔：起始于顶分型，终止于底分型
- 笔序列中相邻笔方向必然交替（上→下→上→下...）

### 1.4 线段（第7-8课，第77课修正）

**定义**：线段由至少3笔构成，线段被特征序列破坏时结束。

**特征序列**：将笔序列中与线段方向相反的笔称为该线段的特征序列。
- 向上线段的特征序列 = 所有向下笔
- 向下线段的特征序列 = 所有向上笔

**特征序列的包含处理**：
- 向上线段中，特征序列（向下笔）做**低低合并**
- 向下线段中，特征序列（向上笔）做**高高合并**

**线段破坏条件（第77课标准）**：
- **第一种破坏**：特征序列的一笔直接击穿前一笔的极值
  - 向上线段中：某向下笔 low < 前一向下笔 low（向下笔创新低）
  - 向下线段中：某向上笔 high > 前一向上笔 high（向上笔创新高）
- **第二种破坏**：特征序列之间存在缺口，且后续笔确认
  - 缺口型破坏需要额外的确认条件

**线段的层级意义**：
- 线段是笔的上一级结构
- 线段是构建中枢的基础元素
- 线段的级别高于笔的级别

### 1.5 中枢（第20-22课）

**定义**：中枢由至少3条连续线段构成的重叠区间。

**中枢的数学定义**：
- ZG（中枢上沿）= MIN(所有构成线段的高点)
- ZD（中枢下沿）= MAX(所有构成线段的低点)
- ZG > ZD 才构成有效中枢
- GG（中枢高点）= MAX(所有构成线段的高点)
- DD（中枢低点）= MIN(所有构成线段的低点)

**中枢的延伸**：
- 后续线段如果高低点仍在 [DD, GG] 范围内，则延伸中枢
- 延伸后 ZG/ZD 需重新计算
- 如果 ZG ≤ ZD，中枢被破坏

**笔级别中枢（降级）**：
- 当线段不足3段时，可退化为"笔级别中枢"
- 笔级别中枢由至少3笔的重叠区间构成
- level=0 标记为笔级别中枢，level=1 标记为线段级别中枢

### 1.6 走势类型（第21-22课）

**走势的分类**：
- **上涨趋势**：由至少两个依次升高的中枢构成
  - 后一个中枢的 ZG > 前一个中枢的 ZG，且 ZD > 前一个中枢的 ZD
- **下跌趋势**：由至少两个依次降低的中枢构成
  - 后一个中枢的 ZD < 前一个中枢的 ZD，且 ZG < 前一个中枢的 ZG
- **盘整**：只包含一个中枢的走势

**走势的完成**：
- 走势必完美——任何级别的走势类型最终都要完成
- 完成后必然转向其他类型
- 未完成的走势类型会继续演化

## 二、核心理论

### 2.1 走势必完美（第2、21课）

**原理**：任何级别的任何走势类型，最终都要完成。完成后一定会转化为其他走势类型。

**推论**：
- 任何走势都可以分解为已完成和未完成两部分
- 未完成的走势一定会延续到完成
- "完成"不等于"结束"——完成的走势可能立刻开始新的同方向走势

**实操意义**：
- 不要在走势未完成时猜测方向
- 走势完成的位置就是买卖点
- 多级别联立可以精确定位走势完成点

### 2.2 走势分解定理（第22-23课）

**走势分解定理一**：任何级别的任何走势，都可以分解为"上涨+下跌+盘整"的连接。

**走势分解定理二**：任何级别的任何走势，都至少由一个该级别的中枢构成。

**重要推论**：
- 盘整+盘整 ≠ 更大级别的盘整（这是常见误解）
- 上涨+下跌的连接，在连接点必然产生买卖点
- 走势的分解是走势分析的基础

### 2.3 区间套（第27-28课）

**定义**：从大级别到小级别逐层递归定位精确买卖点的方法。

**操作步骤**：
1. 确定大级别走势的背驰段
2. 在背驰段内，切换到次级别
3. 在次级别中寻找背驰点
4. 逐级递归，直到最小级别
5. 最小级别的背驰点就是精确的买卖点

**实操要求**：
- 至少需要两个级别联立
- 大级别定方向，小级别定点位
- 多级别背驰共振的信号最可靠

### 2.4 走势转折的判断（第29-30课）

**走势转折的充要条件**：任何级别的走势转折，必然是由该级别的背驰引发的。

**但**：背驰是走势转折的**必要条件**，不是**充分条件**。
- 有背驰不一定转折（背驰后可能形成中枢延伸）
- 转折一定有背驰

**背驰后的三种走势**：
1. **最后一个中枢的级别扩展**：背驰后价格回到最后一个中枢，中枢延伸
2. **更大级别的盘整**：背驰后形成更大级别的中枢
3. **该级别以上级别的反趋势**：背驰后走势反转（最常见的情况）

## 三、背驰理论

### 3.1 背驰的定义（第24-25课）

**定义**：背驰是指走势力度衰减的现象，表现为价格创新高/新低，但力度指标（MACD等）未能同步创新高/新低。

**顶背驰**：
- 向上笔创新高（当前向上笔 high > 前一向上笔 high）
- 但该笔区间内 MACD 正值面积 < 前一个向上笔的 MACD 正值面积
- 预示上涨力度衰减

**底背驰**：
- 向下笔创新低（当前向下笔 low < 前一向下笔 low）
- 但该笔区间内 |MACD 负值面积| < 前一个向下笔的 |MACD 负值面积|
- 预示下跌力度衰减

### 3.2 背驰的判断方法

**推荐方法（基于笔的背驰识别）**：
1. 将笔按方向分为向上笔序列和向下笔序列
2. 比较相邻同方向笔的 MACD 面积
3. 价格创新高/新低但 MACD 面积缩小 = 背驰

**基于线段的背驰**（更高级别，更可靠）：
- 方法同上，但用线段代替笔
- 线段级别背驰的信号更少但更可靠

**背驰强度量化**：
- ratio = 当前面积 / 前一面积
- ratio < 0.3 → 强背驰（STRONG）
- 0.3 ≤ ratio < 0.7 → 中等背驰（MODERATE）
- ratio ≥ 0.7 → 弱背驰（WEAK）

### 3.3 MACD 与背驰（第25-26课）

**MACD 参数**：DIF = EMA(12) - EMA(26)，DEA = EMA(DIF, 9)，MACD = (DIF - DEA) × 2

**MACD 状态判断**：
- **强看多**（strong_bullish）：DIF > DEA 且 MACD > 0
- **看多**（bullish）：DIF > DEA 且 MACD ≤ 0
- **回调**（pullback）：DIF < DEA 且 MACD > 0
- **看空**（bearish）：DIF < DEA 且 MACD ≥ 0 且 DIF ≥ 0
- **强看空**（strong_bearish）：DIF < 0 且 MACD < 0

**金叉/死叉**：
- 金叉：DIF 从下方穿越 DEA
- 死叉：DIF 从上方穿越 DEA

## 四、三类买卖点

### 4.1 第一类买卖点（第13-15课）

**第一类买点**：下跌趋势中，最后一个向下笔底背驰，形成底分型确认。
- 必要条件：下跌趋势 + 底背驰
- 确认信号：底分型形成
- 风险：背驰后可能形成中枢延伸（不反转）
- 止损位：底背驰低点下方 1-2%
- 目标位：前一个反弹高点

**第一类卖点**：上涨趋势中，最后一个向上笔顶背驰，形成顶分型确认。
- 必要条件：上涨趋势 + 顶背驰
- 确认信号：顶分型形成
- 风险：背驰后可能形成中枢延伸
- 止损位：顶背驰高点上方 1-2%

### 4.2 第二类买卖点（第16-17课）

**第二类买点**：第一类买点后的上涨回调，回调低点不低于第一类买点低点。
- 性质：趋势延续信号
- 条件：回调不破前低 + 底分型确认
- 可靠性：比第一类买点更可靠
- 止损位：回调低点下方

**第二类卖点**：第一类卖点后的下跌反弹，反弹高点不高于第一类卖点高点。
- 性质：趋势延续信号
- 条件：反弹不破前高 + 顶分型确认
- 止损位：反弹高点上方

### 4.3 第三类买卖点（第18-19课）

**第三类买点**：向上突破中枢上沿（ZG），且不回拉入中枢。
- 性质：趋势确认信号（最可靠的买点）
- 条件：突破 ZG + 回调不入中枢
- 意义：中枢震荡结束，新趋势开始
- 止损位：中枢上沿 ZG 下方
- 目标位：突破价 × 1.05

**第三类卖点**：向下突破中枢下沿（ZD），且不回拉入中枢。
- 性质：趋势确认信号
- 条件：突破 ZD + 反弹不入中枢
- 止损位：中枢下沿 ZD 上方

### 4.4 买卖点优先级

**可靠性排序**：第三类 > 第二类 > 第一类
- 第三类买/卖点有中枢确认，最可靠
- 第二类是趋势延续确认，中等可靠
- 第一类依赖背驰判断，风险最高

**操作原则**：
- 第三类买/卖点是最佳入场/离场点
- 第一类买/卖点需要背驰确认，不追
- 第二类买/卖点是趋势延续信号，可加仓
- 震荡市中谨慎操作，控制仓位

## 五、多级别联立分析

### 5.1 级别关系

**缠论级别体系**：
```
1分钟 → 5分钟 → 30分钟 → 日线 → 周线 → 月线
  笔     笔      笔      笔     笔     笔
  线段   线段    线段    线段   线段   线段
  中枢   中枢    中枢    中枢   中枢   中枢
```

**级别间的对应关系**：
- 本级别的笔 ≈ 次级别的线段
- 本级别的线段 ≈ 次次级别的走势类型
- 本级别的中枢 ≈ 由3条次级别走势类型构成

### 5.2 多级别分析原则

1. **大级别定方向**：大级别的走势方向决定操作方向
2. **小级别定点位**：小级别的背驰点决定进出时机
3. **多级别共振**：多个级别同时出现买卖点信号，可靠性最高
4. **级别矛盾处理**：大小级别方向矛盾时，以大级别为准

### 5.3 实操中常用的周期组合

- **短线**：15分钟 + 1小时 + 4小时
- **中线**：1小时 + 4小时 + 日线
- **长线**：4小时 + 日线 + 周线

## 六、风控原则

### 6.1 缠论风控体系

1. **走势必完美** → 走势未完成不操作
2. **背驰确认** → 无背驰不操作
3. **买卖点纪律** → 只在买卖点操作
4. **级别匹配** → 操作级别与资金规模匹配
5. **止损硬约束** → 背驰判断错误时果断止损

### 6.2 仓位管理

- 单笔交易最大亏损不超过 2%
- 第一类买卖点：小仓位试探（10-15%）
- 第二类买卖点：加仓（15-20%）
- 第三类买卖点：主仓位（20-30%）
- 总仓位不超过 80%

### 6.3 操作纪律

1. **不臆测**：结构未完成就说"未完成"，不强行定论
2. **不迎合**：分析结论不受"希望市场涨/跌"影响
3. **不糊弄**：有争议的结构标注"观察中"
4. **不甩锅**：决策失误主动承认，不找借口
5. **不遗漏**：关键风险必须上报
6. **不造假**：模拟盘结果如实记录
7. **不干扰**：收到冷却信号后立即停止

## 七、常见误区与纠正

### 7.1 分型识别的误区
- ❌ 不处理K线包含关系直接识别分型
- ✅ 必须先处理包含关系，再识别分型

### 7.2 笔的误区
- ❌ 顶底分型之间没有间隔要求
- ✅ 顶底分型之间至少有一根独立K线

### 7.3 线段的误区
- ❌ 线段只需要3笔就能构成
- ✅ 线段至少3笔，但必须基于特征序列破坏判断线段结束
- ❌ 用滑动窗口扫描判断线段
- ✅ 必须使用特征序列包含处理 + 破坏判断

### 7.4 中枢的误区
- ❌ 中枢只能由线段构成
- ✅ 线段不足时可以降级为笔级别中枢
- ❌ 中枢只看3个元素
- ✅ 中枢可以延伸，后续元素仍在[DD,GG]范围内则延伸

### 7.5 背驰的误区
- ❌ 用滑动窗口扫描每根K线判断背驰
- ✅ 必须基于笔/线段的MACD面积比较
- ❌ 任何MACD面积缩小都是背驰
- ✅ 必须价格创新高/新低 + MACD面积缩小
